# Conflictos

- Conflicto de versiones de dependencias en `pom.xml` al intentar actualizar bibliotecas de Spring.
- Incompatibilidades entre la lógica de negocio actual y cambios de estructura en la capa de datos.
- Problemas de concurrencia al registrar ventas simultáneas desde diferentes clientes.
- Dificultades para sincronizar los cambios de frontend y backend debido a rutas y nombres de campos inconsistentes.
- Conflictos de encodings y caracteres especiales en los datos importados desde la base de datos.
